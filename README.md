# Quantitative Finance with Machine Learning

A quantitative finance project using Python and machine learning to forecast SPY returns. Compares Linear Regression and Random Forest models against a baseline, evaluates predictive performance, and backtests trading strategies against a buy-and-hold benchmark.

## Project Objectives
- Explore whether historical market data can help predict SPY returns.
- Compare Linear Regression and Random Forest models against a baseline.
- Evaluate whether predictive performance translates into better historical trading results.
- Compare model-driven trading strategies with a buy-and-hold benchmark.

## Dataset
Historical SPY market data used to construct predictive features and evaluate return forecasts.

## Methodology
- **Data Preparation:** Cleaned and prepared market data for modelling.
- **Feature Engineering:** Constructed features from historical market information.
- **Model Development:** Trained Linear Regression and Random Forest models.
- **Model Evaluation:** Compared predictive performance against a baseline.
- **Backtesting:** Evaluated trading strategies against buy-and-hold.

## Tools & Technologies
Python · pandas · NumPy · scikit-learn · Matplotlib

## Key Findings
Summarise the models' predictive performance and whether the backtested strategies outperformed the buy-and-hold benchmark. Include actual metrics and results from the project.

## Limitations
Financial returns are noisy and difficult to predict. Backtested performance depends on the evaluation period, feature selection and trading assumptions; historical results do not guarantee future performance.
